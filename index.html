            忘记密码？

            本站使用本地账号：账号保存在当前浏览器的 localStorage 中，没有服务器， 也没有邮箱，所以无法找回或重置密码。

            如果忘记密码，可以清除本站的浏览器数据（开发者工具 → Application → Local Storage）， 然后重新注册账号。清除后，本机保存的所有本地账号都会被删除。

            隐私说明

            这是一个纯静态个人网站，没有后端，也不会把你的账号密码发送到任何地方。

            • 账号 —— 保存在当前浏览器的 localStorage 中，键名为 oihuu.accounts.v1。
            • 密码 —— 不以明文保存：密码会先加盐，再经过多轮 SHA-256 哈希后才写入。
            • 登录状态 —— 保存在 oihuu.session.v1，用于保持登录。
            • 主题 —— 保存在 oihuu.theme.v1。
            • 不使用 Cookie，不接入统计，不加载第三方资源。

            清除本站的浏览器数据会永久删除所有本地账号。

            如何修改主页内容

            这是一个纯静态站点，个人资料直接写在 index.html 里，改完提交到仓库即可自动更新。

            1. 打开 index.html，搜索 const PROFILE = {
            2. 修改 handle、bio、location、email、projects、skills 等字段
            3. 保存并提交到 GitHub 仓库，GitHub Pages 会自动重新部署
            const PROFILE = {
  handle: "OIHUU",
  bio: "你好，欢迎来到我的个人主页。……",
  location: "",              // 留空则不显示
  email: "",                 // 留空则不显示
  github: "https://github.com/OIHUU",
  website: "https://oihuu.github.io",
  projects: [ ... ],
  skills: [ ... ]
};

            主页只显示用户名，不显示真实姓名；登录账号（用户名 / 密码）保存在浏览器本地，和主页资料是分开的。
